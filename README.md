# AI Voice Interview Simulator

A professional AI-powered interview preparation platform built with:

- Streamlit
- OpenAI GPT
- Whisper (Speech-to-Text)
- gTTS (Text-to-Speech)
- SQLite
- Docker (Hugging Face Deployment)

## Features

- User Authentication
- Voice + Text Interview Mode
- Dynamic AI Questions
- AI Evaluation & Feedback
- Confidence Scoring
- Grammar Correction
- Performance Analytics
- Pass/Fail Decision
- Secure API via Secrets

## Deployment

This project is deployed using Docker on Hugging Face Spaces.

### Required Secret:
OPENAI_API_KEY
